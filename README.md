# empresa-retail

Diseño de la base de datos de una empresa retail, realizado como trabajo académico. Registra clientes, canales, campañas e interacciones, entre otros datos. Los datos de ejemplo son ficticios.

![Diagrama entidad-relación](ERR%20Diagrama.png)

## Contenido

- `ERR Diagrama.png`: diagrama entidad-relación.
- `MER_Empresa_retail/`: modelo en MySQL Workbench (`.mwb`).
- `query_empresa_retail.sql`: consultas de inserción, selección, actualización y borrado.
- `Normalizacion/`: ejercicios de normalización de cinco casos (pedidos, películas, tienda, biblioteca y vivero).

## Tecnologías

MySQL, MySQL Workbench y SQL.

El control de acceso de esta base de datos está en [empresa-retail-admin](https://github.com/MariioDk/empresa-retail-admin).
